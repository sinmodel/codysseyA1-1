# 프롬프트 관리 프로그램

## 1. 프로그램 소개

프롬프트 관리 프로그램은 Python으로 제작한 콘솔 기반 프롬프트 관리 프로그램입니다.

프롬프트를 등록하고 목록으로 확인할 수 있으며, 키워드 검색과 카테고리별 조회, 즐겨찾기 관리, 상세 보기 등의 기능을 제공합니다.

프로그램 실행 중 등록한 프롬프트와 즐겨찾기 상태는 실행 중에 유지되며, 프로그램을 종료하면 초기 상태로 돌아갑니다.

---

## 2. 개발 환경

- Python 3.10 이상
- Visual Studio Code
- Git
- GitHub

---

## 3. 실행 방법

터미널에서 프로젝트 폴더로 이동한 후 다음 명령어를 실행합니다.

```bash
python prompt_manager3.py
```

프로그램이 실행되면 메뉴에서 원하는 기능의 번호를 입력하여 사용할 수 있습니다.

---

## 4. 주요 기능

### 1. 프롬프트 등록
- 새로운 프롬프트를 등록할 수 있습니다.
- 제목, 카테고리, 내용을 입력합니다.
- 빈 입력을 방지합니다.
- 동일한 제목의 중복 등록을 방지합니다.
- 새로 등록된 프롬프트의 즐겨찾기 기본값은 `False`입니다.

### 2. 프롬프트 목록 보기
- 등록된 모든 프롬프트를 번호와 함께 확인할 수 있습니다.
- 제목과 카테고리를 표시합니다.
- 즐겨찾기로 등록된 프롬프트에는 `⭐`가 표시됩니다.

### 3. 프롬프트 검색
- 제목, 내용, 카테고리를 기준으로 키워드를 검색할 수 있습니다.
- 검색 결과를 번호와 함께 표시합니다.
- 즐겨찾기된 프롬프트에는 `⭐`가 표시됩니다.
- 검색 결과가 없으면 안내 메시지를 표시합니다.
- 검색어가 비어 있으면 입력 안내 메시지를 표시합니다.

### 4. 카테고리별 조회
- 입력한 카테고리에 해당하는 프롬프트를 조회할 수 있습니다.
- 해당 카테고리의 프롬프트가 없으면 안내 메시지를 표시합니다.
- 카테고리 입력이 비어 있으면 입력 안내 메시지를 표시합니다.

### 5. 즐겨찾기 등록/해제
- 프롬프트 번호를 입력하여 즐겨찾기를 등록하거나 해제할 수 있습니다.
- 현재 즐겨찾기 상태를 확인할 수 있습니다.
- 잘못된 번호를 입력하면 안내 메시지를 표시합니다.

### 6. 즐겨찾기 목록
- 즐겨찾기로 등록된 프롬프트만 모아서 확인할 수 있습니다.
- 즐겨찾기가 없으면 안내 메시지를 표시합니다.

### 7. 상세 보기
- 프롬프트의 제목을 입력하여 상세 내용을 확인할 수 있습니다.
- 제목, 카테고리, 내용 전체, 즐겨찾기 상태를 표시합니다.
- 존재하지 않는 프롬프트를 입력하면 안내 메시지를 표시합니다.
- 상세 보기가 완료되면 완료 안내 메시지를 표시합니다.

### 0. 종료
- 프로그램을 종료합니다.

## 5. 기본 프롬프트 데이터

프로그램 시작 시 다음과 같은 프롬프트가 기본 데이터로 등록되어 있습니다.

| 제목 | 카테고리 | 내용 |
|---|---|---|
| Python 학습 | 개발 | Python을 쉽게 설명해 주세요. |
| 회의록 요약 | 업무 | 회의 내용을 핵심 내용 중심으로 요약해 주세요. |
| 영상 제작 | 영상 | 영상 제작을 위한 장면 구성과 프롬프트를 만들어 주세요. |

프롬프트 데이터는 Python의 **리스트와 딕셔너리**를 사용하여 관리합니다.

각 프롬프트는 다음 정보를 포함합니다.

- 제목
- 카테고리
- 내용
- 즐겨찾기 여부

---

## 6. 프롬프트 카테고리

현재 기본으로 등록된 프롬프트에서 사용하는 카테고리는 다음과 같습니다.

- 개발
- 업무
- 영상

사용자가 새로운 프롬프트를 등록할 때 카테고리를 직접 입력할 수 있습니다.

---

## 7. 프로그램 메뉴

```text
=================================
      프롬프트 관리 프로그램
=================================

1. 프롬프트 등록
2. 프롬프트 목록 보기
3. 프롬프트 검색
4. 카테고리별 조회
5. 즐겨찾기 등록/해제
6. 즐겨찾기 목록
7. 상세 보기
0. 종료
```

---

## 8. 코드 구조

프로그램의 기능을 하나의 함수에 모두 작성하지 않고 기능별로 함수를 분리하여 구성했습니다.

주요 함수는 다음과 같습니다.

- `show_menu()` : 프로그램 메뉴 출력
- `add_prompt()` : 프롬프트 등록
- `show_list()` : 프롬프트 목록 출력
- `search_prompt()` : 프롬프트 검색
- `show_by_category()` : 카테고리별 조회
- `toggle_favorite()` : 즐겨찾기 등록/해제
- `show_favorites()` : 즐겨찾기 목록 출력
- `show_detail()` : 프롬프트 상세 보기
- `main()` : 프로그램 실행 및 메뉴 선택 처리

---

## 9. Git을 이용한 버전 관리

프로그램의 기능을 단계별로 개발하고 Git을 이용하여 변경 이력을 관리했습니다.

주요 작업 내용:

- 기능별 커밋 작성
- `feature/detail-improvement` 브랜치 생성
- 브랜치에서 상세 보기 기능 개선
- 기능 개선 후 커밋
- `main` 브랜치로 병합

이를 통해 기능 단위로 변경 사항을 관리하고 브랜치와 병합 과정을 실습했습니다.
