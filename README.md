# 프롬프트 관리 프로그램
과제 제출자 : sinmodel(신재풍)

## 1. 프로그램 소개

Python으로 작성한 콘솔 기반 프롬프트 관리 프로그램입니다.

프롬프트를 등록하고 목록, 검색, 카테고리별 조회, 즐겨찾기, 상세 보기 등의 기능을 사용할 수 있습니다.
또한 프롬프트를 JSON 파일로 저장하고 불러오며, 카테고리별 Markdown 파일로 내보낼 수 있습니다.

프로그램 실행 중에는 프롬프트를 추가·수정·삭제할 수 있으며, 상세 보기 횟수를 기록하여 사용 횟수 Top 목록으로 확인할 수 있습니다.

---

## 2. 개발 환경

- Python 3.10 이상
- Visual Studio Code
- Git
- GitHub

---

## 3. 실행 방법

프로그램 파일이 있는 폴더에서 다음 명령어를 실행합니다.

```bash
python prompt_manager3.py
```

프로그램이 실행되면 메뉴 번호를 입력하여 원하는 기능을 선택할 수 있습니다.

---

## 4. 주요 기능

### 1. 프롬프트 등록

- 제목, 카테고리, 내용을 입력하여 새로운 프롬프트를 등록합니다.
- 제목, 카테고리, 내용은 빈 값으로 등록할 수 없습니다.
- 동일한 제목의 중복 등록을 방지합니다.
- 새로 등록한 프롬프트의 즐겨찾기 상태는 미등록으로 시작합니다.
- 사용 횟수는 0부터 시작합니다.

### 2. 프롬프트 목록

- 등록된 모든 프롬프트를 번호와 함께 확인합니다.
- 제목과 카테고리를 표시합니다.
- 즐겨찾기 등록 상태를 ⭐로 표시합니다.

### 3. 프롬프트 검색

- 제목, 내용, 카테고리에 포함된 키워드로 프롬프트를 검색합니다.
- 검색 결과에 번호와 즐겨찾기 상태를 함께 표시합니다.
- 검색 결과가 없을 경우 안내 메시지를 표시합니다.
- 검색어가 비어 있으면 입력 안내 메시지를 표시합니다.

### 4. 카테고리별 조회

- 입력한 카테고리에 해당하는 프롬프트를 조회합니다.
- 해당 카테고리의 프롬프트가 없으면 안내 메시지를 표시합니다.
- 카테고리를 입력하지 않은 경우 입력 안내 메시지를 표시합니다.

### 5. 즐겨찾기 등록/해제

- 프롬프트 번호를 입력하여 즐겨찾기를 등록하거나 해제합니다.
- 현재 즐겨찾기 상태에 따라 등록/해제가 전환됩니다.
- 잘못된 번호를 입력하면 안내 메시지를 표시합니다.

### 6. 즐겨찾기 목록

- 즐겨찾기로 등록된 프롬프트만 모아서 확인합니다.
- 즐겨찾기가 없을 경우 안내 메시지를 표시합니다.

### 7. 상세 보기

- 프롬프트 번호를 입력하여 상세 내용을 확인합니다.
- 제목, 카테고리, 내용, 즐겨찾기 상태를 표시합니다.
- 상세 보기를 실행할 때마다 사용 횟수가 1 증가합니다.
- 잘못된 번호나 숫자가 아닌 입력을 처리합니다.
- 상세 보기 완료 안내를 표시합니다.

### 8. Markdown 내보내기

- 등록된 프롬프트를 카테고리별 Markdown 파일로 저장합니다.
- 같은 카테고리의 프롬프트는 하나의 Markdown 파일에 함께 저장됩니다.
- 내보내기가 완료되면 안내 메시지를 표시합니다.

### 9. 프롬프트 수정

- 기존 프롬프트를 제목으로 찾아 수정합니다.
- 제목, 카테고리, 내용을 수정할 수 있습니다.
- 수정 시에도 중복 제목 등록을 방지합니다.

### 10. 프롬프트 삭제

- 기존 프롬프트를 제목으로 찾아 삭제합니다.
- 삭제할 프롬프트가 없으면 안내 메시지를 표시합니다.

### 11. 사용횟수 Top 목록

- 상세 보기로 기록된 사용 횟수를 기준으로 프롬프트를 정렬하여 표시합니다.
- 각 프롬프트의 사용 횟수를 함께 확인할 수 있습니다.

### 0. 종료

- 프로그램 종료 전에 프롬프트 데이터를 `prompts.json`에 저장합니다.
- 다음 실행 시 저장된 데이터를 불러옵니다.

---

## 5. JSON 데이터 저장

프로그램은 프롬프트 데이터를 JSON 형식으로 저장하고 불러옵니다.

저장 파일:

```text
prompts.json
```

프롬프트 데이터에는 다음 정보가 포함됩니다.

- 제목
- 카테고리
- 내용
- 즐겨찾기 상태
- 사용 횟수

`prompts.json`은 프로그램 실행 과정에서 생성되는 데이터 파일이므로 Git 관리 대상에서는 제외하도록 `.gitignore`에 설정했습니다.

---

## 6. Markdown 내보내기

등록된 프롬프트는 카테고리별 Markdown 파일로 내보낼 수 있습니다.

예:

```text
개발.md
업무.md
영상.md
기타.md
```

각 Markdown 파일에는 해당 카테고리에 속한 프롬프트의 제목과 내용이 저장됩니다.

## 10. 코드 구조

프로그램의 기능을 함수별로 분리하여 작성했습니다.

주요 함수:

- `show_menu()` : 프로그램 메뉴 출력
- `add_prompt()` : 프롬프트 등록
- `show_list()` : 프롬프트 목록 출력
- `search_prompt()` : 프롬프트 검색
- `show_by_category()` : 카테고리별 조회
- `toggle_favorite()` : 즐겨찾기 등록/해제
- `show_favorites()` : 즐겨찾기 목록 출력
- `show_detail()` : 프롬프트 상세 보기 및 사용 횟수 기록
- `export_to_markdown()` : Markdown 내보내기
- `update_prompt()` : 프롬프트 수정
- `delete_prompt()` : 프롬프트 삭제
- `show_usage_top()` : 사용 횟수 Top 목록 출력
- `save_prompts()` : JSON 저장
- `load_prompts()` : JSON 불러오기
- `main()` : 프로그램 실행 및 메뉴 선택 처리

## 11. Git을 이용한 버전 관리

프로그램 기능을 단계별로 개발하면서 Git을 이용해 변경 이력을 관리했습니다.

주요 작업:

- 기본 프롬프트 관리 기능 작성
- 검색 및 입력값 검증 기능 개선
- 즐겨찾기 기능 개선
- 상세 보기 기능 개선
- JSON 저장 및 불러오기 기능 추가
- Markdown 내보내기 기능 추가
- 학습 과정에서 작성한 재사용 프롬프트 추가
- 프롬프트 수정 및 삭제 기능 추가
- 사용 횟수 기록 및 Top 목록 기능 추가
- 기능 개선을 위한 Feature Branch 생성 및 Main Branch 병합
- GitHub 저장소에 최종 코드 업로드

Feature Branch 예:

```text
feature/detail-improvement
```

## 13. 프로젝트 목적

이 프로젝트는 프롬프트를 단순히 작성하는 데 그치지 않고, 자주 사용하는 프롬프트를 체계적으로 등록하고 검색하며 다시 활용할 수 있도록 관리하는 것을 목적으로 합니다.

또한 Python의 리스트와 딕셔너리, 함수, 조건문, 반복문, JSON 데이터 처리, 파일 입출력 및 Git 버전 관리 등을 하나의 프로그램에 적용하면서 실습할 수 있도록 구성했습니다.
